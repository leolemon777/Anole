## 准备（研究者，每名参与者前）

1. 干净 Win11 VM 快照（无 LibreOffice/FFmpeg 等系统引擎；与 clean-VM 认证共享镜像，目的不同）。
2. 最新 release candidate 安装包放在桌面，**不要**替参与者安装。
3. 录屏 + 计时。观察者只记录，不指导；参与者卡死 90 秒以上才允许一句最多提示，并在记录表标注。
4. 参与者画像：非开发者，日常用 Windows，最近转换过文件（图片/文档任一）。

## 任务单（发给参与者，原话照读）

> 1. 桌面上有一个安装包。安装这个软件，打开它。
> 2. 把桌面上的 `sample-说明书.pdf` 转成图片（你理解的"转成图片"就行）。
> 3. 在文件资源管理器里，对 `sample-照片.png` 右键，把它转成 WebP。
> 4. 桌面上的 `相册` 文件夹里是一批照片，把整个文件夹转成 JPG。
> 5. 你觉得刚才的转换"转对了吗"？在应用里找到证据，说出你的判断。
